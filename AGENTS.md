# Windows Island — инструкции агентам

Перед изменением проекта или взаимодействием через MCP прочитайте `README.md`, особенно «Статус реализации» и «Правила для Codex, Claude и других агентов (контракт 0.2)».

- Актуальная сборка — release/Windows-Island-0.3.9.exe. Она содержит компактную капсулу, мини-полоску и таймер в капсуле и перетягивание. Различайте актуальную сборку, старый exe 0.1 и дизайн-макет; проверяйте функции после новых изменений.
- Сначала обнаружьте инструменты MCP и прочитайте island_get_day; используйте реальные id из ответа.
- План дня передавайте через island_import_tasks со стабильными source и externalId.
- Результат агента передавайте через island_report_work со стабильным eventId. Не дублируйте его island_notify или island_complete_task.
- Для самостоятельного сообщения используйте island_notify; target должен содержать реальное приложение и только проверенную ссылку.
- Не редактируйте пользовательскую базу напрямую, не раскрывайте токен подключения, не считайте ошибку MCP успешной операцией.
- Таймер учитывает время, а не запускает произвольные команды. Сохраните единую капсулу и обратимое раскрытие при изменениях UI.
- В 0.3 календарь скрыт в UI, но его данные и MCP сохранены. Музыка берётся из системной медиасессии, команды зависят от возможностей плеера. Закрытие группы уведомлений скрывает сообщения, сохраняя защиту от повторной доставки; задачи и отчёты не удаляются. Для Telegram допустимы source/target.app `telegram` и проверенные ссылки `tg:`.
- В 0.3.3 системные события временные (3 секунды), без сохранения в истории. Круглые капсулы расположены отдельно справа; пустой промежуток пропускает клики. Ctrl+W/Alt+F4 сворачивают Island; выход доступен только через трей или контекстное меню. Обновления сразу выбирают самую новую стабильную версию, без цепочки промежуточных сборок.
- Проверяйте `settings.tasksEnabled` из `island_get_day`: при `false` не добавляйте, не запускайте и не меняйте задачи; не отправляйте `taskId` в отчёте агента. Самостоятельные уведомления и отчёты без привязки к задаче доступны. Отключение задач сохраняет данные и ставит таймер на паузу.
- Настройки языка (`ru`/`en`), папки отчётов и функций меняются пользователем через UI. Не меняйте их через пользовательскую базу. Отключённая погода возвращает ошибку MCP. Системные уведомления VPN/батареи/Wi-Fi не сохраняются; анимации зарядки работают только во время показа.
- Продакшен не включает браузерное демо. Сборку фронтенда проверяет `scripts/check-production.mjs`; медиасессия обслуживается `native/MediaBridge.cs` в одном `IslandBridge.exe`, без отдельного PowerShell.

- В 0.3.3 горячая клавиша задаётся пользователем. Игровой оверлей выключен по умолчанию; только явно закреплённый оверлей допускается поверх полноэкранного окна. CPU/RAM/PDH читаются нативно; температуры требуют WMI-провайдера LibreHardwareMonitor/OpenHardwareMonitor, FPS — RTSS. Не подменяйте недоступные метрики вымышленными значениями. Опрос останавливается при скрытии.

- В 0.3.4 буфер отслеживается только по последовательности/форматам: не читайте и не передавайте содержимое. Нотисы копирования временные. Запись экрана запускает пользователь в «Инструменты»; MCP не получает доступ к экрану/микрофону. Отключение инструментов останавливает запись с сохранением. WebM сохраняется в Видео/Windows Island, ошибка не считается успешным роликом. Сохраняйте обработку выхода и потоковую запись без накопления видео в RAM.

- В 0.3.5 activeTransparency/backgroundBlur (0–100) меняют только активную поверхность. Сохраняйте мини-прозрачность, резкость содержимого, нативную маску подложки/круглых элементов, пропуск кликов и исключение подложки из записи. CSS backdrop-filter не размывает другие окна Windows.

- В 0.3.6 индикаторы ИИ получают реальные события hooks или island_agent_activity. Не определяйте работу по открытому окну/процессу. Используйте стабильный sessionId, working/needs_input/idle; не создавайте ручной статус при подключённых hooks. Статус временный и независим от задач. Не отключайте проверку доверия hooks Codex и не изменяйте записи доверия.

- В 0.3.7 сводка «Ваш день» запускается через 20 секунд, временная и без истории. Не прерывайте раскрытый интерфейс/запись/другие уведомления. Дневная и вечерняя температуры — почасовые 14:00/19:00 города; не называйте суточный минимум вечерней температурой. Учитывайте greeting/quiet/tasksEnabled/weatherEnabled.

- В 0.3.8 размытие ограничивает CompositionGeometricClip внутри native/ClippedBackdrop.cs, а не только HRGN окна. Сохраняйте чёткий фон снаружи округлого контура, в промежутках и ниже маленькой капсулы; проверяйте реальный рабочий стол и исключение слоя из записи.

- В 0.3.9 ввод ограничивает BrowserWindow.setShape (electron/hit-shape.cjs), а HWND размытия — SetWindowRgn. Не возвращайте зависимость кликов от опроса курсора. При захвате жеста форма временно сбрасывается; при отпускании, снятии fullscreen-блокировки и изменении DPI восстанавливается. Проверяйте настоящие клики в другой процесс.
