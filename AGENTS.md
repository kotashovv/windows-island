# Windows Island — инструкции агентам

Перед изменением проекта или взаимодействием через MCP прочитайте `README.md`, особенно «Статус реализации» и «Правила для Codex, Claude и других агентов (контракт 0.2)».

- Актуальная сборка — release/Windows-Island-0.2.5.exe. Она содержит компактную капсулу, мини-полоску и таймер в капсуле и перетягивание. Различайте актуальную сборку, старый exe 0.1 и дизайн-макет; проверяйте функции после новых изменений.
- Сначала обнаружьте инструменты MCP и прочитайте island_get_day; используйте реальные id из ответа.
- План дня передавайте через island_import_tasks со стабильными source и externalId.
- Результат агента передавайте через island_report_work со стабильным eventId. Не дублируйте его island_notify или island_complete_task.
- Для самостоятельного сообщения используйте island_notify; target должен содержать реальное приложение и только проверенную ссылку.
- Не редактируйте пользовательскую базу напрямую, не раскрывайте токен подключения, не считайте ошибку MCP успешной операцией.
- Таймер учитывает время, а не запускает произвольные команды. Сохраните единую капсулу и обратимое раскрытие при изменениях UI.
