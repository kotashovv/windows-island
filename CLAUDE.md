# Windows Island

Прочитайте `AGENTS.md` и `README.md` перед работой с этим проектом. Контракт взаимодействия находится в разделе README «Правила для Codex, Claude и других агентов (контракт 0.2)».

Используйте source `claude` для своих сообщений и списков. Повторную доставку выполняйте с прежними externalId/eventId. Для результата используйте island_report_work и не отправляйте второе уведомление о том же событии. Проверяйте доступность инструмента и успешность ответа. Актуальная версия release/Windows-Island-0.3.4.exe содержит компактный дизайн, мини-полоску и таймер в капсуле и обратимое перетягивание; exe 0.1 содержит старый интерфейс.

В 0.3.3 пользователь может отключить задачи. Если `island_get_day` вернул `settings.tasksEnabled: false`, не импортируйте и не меняйте задачи, не отправляйте `taskId` в `island_report_work`. Уведомления и самостоятельные отчёты без привязки к задаче продолжают работать. Язык, папку отчётов и функции пользователь выбирает в настройках; не редактируйте его базу напрямую.

В 0.3.4 есть отключаемые уведомления буфера и запись экрана в инструментах. Не читайте содержимое буфера и не запускайте захват от имени агента: MCP не предоставляет таких инструментов. Не удаляйте `.partial` пользователя после ошибки — это файл восстановления.
