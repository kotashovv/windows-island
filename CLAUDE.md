# Windows Island

Прочитайте `AGENTS.md` и `README.md` перед работой с этим проектом. Контракт взаимодействия находится в разделе README «Правила для Codex, Claude и других агентов (контракт 0.2)».

Используйте source `claude` для своих сообщений и списков. Повторную доставку выполняйте с прежними externalId/eventId. Для результата используйте island_report_work и не отправляйте второе уведомление о том же событии. Проверяйте доступность инструмента и успешность ответа. Актуальная версия release/Windows-Island-0.3.8.exe содержит компактный дизайн, мини-полоску и таймер в капсуле и обратимое перетягивание; exe 0.1 содержит старый интерфейс.

В 0.3.3 пользователь может отключить задачи. Если `island_get_day` вернул `settings.tasksEnabled: false`, не импортируйте и не меняйте задачи, не отправляйте `taskId` в `island_report_work`. Уведомления и самостоятельные отчёты без привязки к задаче продолжают работать. Язык, папку отчётов и функции пользователь выбирает в настройках; не редактируйте его базу напрямую.

В 0.3.4 есть отключаемые уведомления буфера и запись экрана в инструментах. Не читайте содержимое буфера и не запускайте захват от имени агента: MCP не предоставляет таких инструментов. Не удаляйте `.partial` пользователя после ошибки — это файл восстановления.

В 0.3.5 activeTransparency/backgroundBlur (0–100) меняют только активную поверхность. Сохраняйте мини-прозрачность, резкость содержимого, нативную маску подложки/круглых элементов, пропуск кликов и исключение подложки из записи. CSS backdrop-filter не размывает другие окна Windows.

В 0.3.6 индикаторы ИИ получают реальные события hooks или island_agent_activity. Не определяйте работу по открытому окну/процессу. Используйте стабильный sessionId, working/needs_input/idle; не создавайте ручной статус при подключённых hooks. Статус временный и независим от задач. Не отключайте проверку доверия hooks Codex и не изменяйте записи доверия.

В 0.3.7 сводка «Ваш день» запускается через 20 секунд, временная и без истории. Не прерывайте раскрытый интерфейс/запись/другие уведомления. Дневная и вечерняя температуры — почасовые 14:00/19:00 города; не называйте суточный минимум вечерней температурой. Учитывайте greeting/quiet/tasksEnabled/weatherEnabled.

В 0.3.8 размытие ограничивает CompositionGeometricClip внутри native/ClippedBackdrop.cs, а не только HRGN окна. Сохраняйте чёткий фон снаружи округлого контура, в промежутках и ниже маленькой капсулы; проверяйте реальный рабочий стол и исключение слоя из записи.
