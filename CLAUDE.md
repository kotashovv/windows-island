# Windows Island

Прочитайте `AGENTS.md` и `README.md` перед работой с этим проектом. Контракт взаимодействия находится в разделе README «Правила для Codex, Claude и других агентов (контракт 0.2)».

Используйте source `claude` для своих сообщений и списков. Повторную доставку выполняйте с прежними externalId/eventId. Для результата используйте island_report_work и не отправляйте второе уведомление о том же событии. Проверяйте доступность инструмента и успешность ответа. Актуальная версия release/Windows-Island-0.3.0.exe содержит компактный дизайн, мини-полоску и таймер в капсуле и обратимое перетягивание; exe 0.1 содержит старый интерфейс.
